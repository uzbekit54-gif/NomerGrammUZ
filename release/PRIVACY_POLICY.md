# Политика конфиденциальности мобильного приложения «NomerGramm UZ»

**Дата вступления в силу:** 14 октября 2026 г.

Настоящая Политика конфиденциальности описывает, как мобильное приложение **NomerGramm UZ** (далее — «Приложение») обрабатывает информацию пользователей.

---

### 1. Архитектура нулевого сбора данных (Zero Data Collection)
Приложение разработано по концепции **Offline-First**:
- Приложение **не собирает, не передаёт и не хранит на внешних серверах** никакие персональные данные пользователей.
- Все операции по распознаванию, поиску и анализу автомобильных номеров осуществляются **строго локально на устройстве пользователя**.
- В приложении отсутствуют сторонние рекламные трекеры, системы аналитики или профилирования пользователей.

---

### 2. Используемые системные разрешения Android

#### 2.1. Доступ к камере (`android.permission.CAMERA`)
- **Назначение:** Используется исключительно для работы функции оптического распознавания текста (OCR) номерных знаков в реальном времени.
- **Обработка данных:** Видеопоток анализируется встроенной библиотекой Google ML Kit непосредственно в оперативной памяти устройства. Кадры камеры, фотографии или видеозаписи **никогда не сохраняются во внешние хранилища и не отправляются по сети**.
- **Добровольность:** Предоставление доступа к камере является добровольным. При отказе пользователь сохраняет полный доступ к ручному поиску и каталогу номеров.

#### 2.2. Локальное хранилище настроек (SharedPreferences / Internal Storage)
- **Назначение:** Используется для сохранения списка избранных номеров, истории недавних запросов и выбранного языка интерфейса.
- **Хранение:** Все сохранённые данные размещаются в защищенном изолированном каталоге Приложения на устройстве и удаляются при удалении Приложения.

---

### 3. Сетевое взаимодействие
- Приложение не требует подключения к сети Интернет для своей базовой функциональности.
- Доступ к сети может использоваться исключительно для ручной проверки обновлений справочной базы данных из открытого репозитория GitHub. При этом передаются только стандартные заголовки HTTP (ETag/User-Agent), без передачи идентификаторов устройства или пользователя.

---

### 4. Соответствие законодательству
Приложение разработано в строгом соответствии с требованиями Закона Республики Узбекистан «О персональных данных» № ЗРУ-547 и политикой безопасности магазина приложений RuStore.
